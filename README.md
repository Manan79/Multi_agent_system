# MCP Practice Session

This repository contains a practice session focused on working with a minimal MCP tool implementation.

## Practice session file

- `MCP Practice/1-practice.py`: A simple FastMCP example with a single `fetch` tool.

## Notes

- The practice session demonstrates how to define and run an MCP tool using `fastmcp`.
- Run the practice example with `python "MCP Practice/1-practice.py"`.
